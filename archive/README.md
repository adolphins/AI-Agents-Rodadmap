# 📂 Archive / 同步传输与存档

本目录用于文件同步与传输。

## 用途

-   跨设备、跨环境之间的文件同步
-   项目相关文件的接收与分发
-   待处理或待整合的文件暂存

## 目录约定

为便于查找和管理，建议按以下规则组织内容：

-   **按用途分类**：`sync/`、`transfer/`、`incoming/`
-   **命名规范**：文件名尽量包含日期或简要描述，如 `eDC Elevate-entry Gate v1.2 - 20260928`

## 注意事项

-   请勿提交敏感信息（密钥、密码、个人隐私数据等）
-   大文件（>50MB）建议使用 Git LFS 或外部链接
-   定期清理已无用的文件，保持目录整洁
