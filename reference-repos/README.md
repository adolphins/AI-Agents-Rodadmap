# 📦 Reference Repos / 参考仓库

本目录用于存放学习过程中参考的 GitHub 开源仓库。

## 用途

-   克隆或保存学习路线图中提到的优质开源项目（如 mlabonne/llm-course、shishpatel26/500-AI-Agents-Projects 等）
-   按主题分类整理，方便快速查阅与对照学习
-   记录每个仓库在本路线图中的参考价值

## 目录约定

建议按以下规则组织内容：

-   **按主题分类**：如 llm-course/、ag/、gents/、inetuning/
-   **命名规范**：使用仓库原始名称，便于与 GitHub 对应
-   可在每个仓库旁添加简短说明（如 README.md 或备注文件），标注参考用途

## 注意事项

-   请勿提交敏感信息（密钥、密码、个人隐私数据等）
-   大文件（>50MB）建议使用 Git LFS 或外部链接
-   定期清理不再使用的仓库，保持目录整洁
