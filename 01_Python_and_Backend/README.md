# Phase 1: Python & Backend Foundations

> Master the programming base and backend skills essential for AI development.

## Goals

- Write advanced Python (OOP, decorators, concurrency) beyond simple scripts.
- Build RESTful APIs with **FastAPI**.
- Handle data cleaning with **Pandas** and **SQL**.
