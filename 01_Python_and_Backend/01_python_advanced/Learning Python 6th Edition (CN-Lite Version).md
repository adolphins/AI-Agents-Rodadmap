#### Why Use Built-in Objects? - 为什么使用内置对象？

在低级语言（如 C）中，你需要手动实现数据结构、管理内存、编写搜索访问代码等，这些工作繁琐易错，且分散精力。

在典型的Python程序中，这类繁重工作基本都消失了。
因为Python**内置了强大的对象类型**，你在开始解决问题之前，通常不需要自己编写对象实现代码。

事实上，除非你需要内置对象无法满足的特殊处理逻辑，否则几乎总是应该优先使用内置对象，而非自己实现。原因如下：

- **内置对象让程序更容易编写**
  对于简单任务，内置对象通常就足以表示问题域的结构。你可以直接使用列表、字典等强大工具，仅凭Python内置对象就能完成大量工作。

- **内置对象是扩展组件的基础**
  处理更复杂的任务时，你可能需要用类或C语言接口自定义对象。但这些自定义对象往往是构建在列表、字典等内置对象之上的。例如，栈结构可以用一个类来管理和定制内置列表实现。

- **内置对象通常比自定义数据结构更高效**
  Python内置对象使用的算法已经过深度优化，且很多是用C这类底层语言实现的，速度极快。你自己很难写出性能能与之匹敌的同类对象。

- **内置对象是语言的标准组成部分**
  你不需要为了开始编程而去实现专属对象类型。而且Python内置对象是统一标准，到处都一样；而私有工具库往往在不同环境中差异很大。

换句话说，内置对象不仅让编程更简单，而且比大多数从零实现的结构更强大、更易用。无论你是否实现新的对象类型，**内置对象都是所有Python程序的核心**。

#### Python's Core Object Types - Python 的核心对象类型

Python 内置了多种核心对象类型，每种都有专用的字面量语法，创建后其操作集即固定（动态但强类型）

**表 4-1 Python 内置（核心）对象**

| 类型     | 字面量/创建示例                                  | 简要说明                                     |
| -------- | ------------------------------------------------ | -------------------------------------------- |
| Numbers - 数字     | `123`, `3.14`, `3+4j`, `Decimal('1.0')`          | 整数、浮点、复数、小数、分数等               |
| Strings - 字符串   | `'code'`, `"app's"`, `b'a\x01c'`, `'h\u00c4ck'`  | 文本（Unicode）或字节序列，不可变            |
| Lists - 列表     | `[1, [2, 'three'], 4.5]`, `list(range(10))`      | 有序、可变、任意嵌套的集合                   |
| Dictionaries - 字典     | `{'job': 'dev', 'years': 40}`, `dict(hours=10)`  | 键值映射，保留插入顺序，可变                 |
| Tuples - 元组     | `(1, 'app', 4)`, `tuple('hack')`                 | 不可变序列，常用于固定集合                   |
| Files - 文件     | `open('data.txt')`, `open(r'C:\data.bin', 'wb')` | 访问外部文件，通过 `open` 创建               |
| Sets - 集合     | `{'a', 'b', 'c'}`, `set('abc')`                  | 无序、唯一元素，支持数学运算                 |
| Other core objects - 其他核心 | `True`, `False`, `None`, `type`                  | 布尔值、空占位符、类型对象                   |
| Program-unit objects - 程序单元 | 函数、模块、类                                   | 通过 `def`、`import`、`class` 创建，也是对象 |
| Implementation objects - 实现相关 | 编译后的代码、栈回溯                             | 通常供工具开发者使用                         |

同样重要的是，对象一旦创建，其支持的操作就固定不变 —— 字符串只能执行字符串操作，列表只能执行列表操作。

正式来讲，这意味着 Python 是动态类型语言，会自动跟踪对象类型，无需编写类型声明代码；同时它也是强类型语言，限制对象只能执行自身类型支持的操作。


#### Numbers - 数字

Python 的核心对象类型里包含最常见的类型：

- 没有小数部分的整数
- 带小数部分的浮点数
- 还有更特殊的类型
    - 带虚部的复数
    - 可变精度的十进制数
    - 带分子分母的分数

内置数字足以表示绝大多数数值，从你的年龄到银行余额，向量、矩阵这类专用数值对象也可以通过第三方库获得。

虽然 Python 提供了更高级的选项，但基本数字对象其实很基础。

Python 的数字支持常规数学运算。比如，加号 + 执行加法，星号 * 表示乘法，两个星号 ** 表示乘方


```python
$ python3           # 启动REPL
>>> 123 + 222       # 整数加法
345
>>> 1.5 * 4         # 浮点数乘法
6.0
>>> 1_234_567, 0x15, bin(21)  # 分隔符、十六进制、二进制
(1234567, 21, '0b10101')
>>> 2 ** 100        # 2的100次方
1267650600228229401496703205376
```

注意最后一个结果：Python 的整数对象会根据需要自动提供超大精度。

你甚至可以在 Python 里计算 2 的 12345 次方，不过结果太长 —— 有近 4000 位，不太容易看懂：

```python
>>> len(str(2 ** 12345))  # 计算多少位
3717
```

这种嵌套调用是从内向外执行的 — 先算出乘方结果，再用内置函数str把它转成数字字符串，最后用len获取字符串长度。

除了表达式，Python 还有一些实用的数值模块，它们只是一些附加工具包，我们需要用import语句导入才能使用：

```python
>>> import math
>>> math.pi
3.141592653589793
>>> math.sqrt(85)
9.219544457292887
```

math模块包含更多高级数值函数，而random模块可以生成随机数和随机选择

```python 
>>> import random
>>> random.random()
0.7082048489415967
>>> random.choice([1, 2, 3, 4])
2
```

Python 还包含更特殊的数值对象 —— 比如复数、定点数、有理数，以及集合和布尔型 —— 第三方开源扩展库则提供更多类型（如矩阵、向量、更高精度数字）。这些对象我们会在本章和本书后面再讲。

到目前为止，我们一直在把 Python 当成简单的计算器使用；为了更全面地介绍它的内置对象，我们接下来继续讲解字符串。

####  Strings 字符串

字符串用于记录文本信息（比如你的名字），以及任意的字节集合（比如图像文件的内容）。

它们是 Python 中我们第一个接触到的序列 —— **按位置顺序排列的对象集合**。序列会保持元素从左到右的顺序：其中的元素按相对位置存储和读取。

严格来说，字符串是单字符的序列；其他更通用的序列对象包括后面会讲到的列表和元组。


##### Sequence Operations

作为序列，字符串支持假定元素按位置排序的操作。

例如，如果我们有一个用引号括起来的 4 字符字符串（单引号和双引号含义相同，单引号更常用、更简洁），我们可以用内置函数len验证它的长度，并用索引表达式获取其中的元素：

```python 
>>> S = 'Code'  # 创建一个4字符字符串
>>> len(S)     # 长度：字符个数
4
>>> S[0]       # S中的第一个元素，索引为0
'C'
>>> S[1]       # 从开头数第二个元素
'o'
```

在 Python 中，索引写在方括号里，表示从开头算起的偏移量，所以从 0 开始：第一个元素在索引 0，第二个在索引 1，依此类推。

我们也可以从尾部反向索引：正数索引从左向右数，负数索引从右向左数。

```python
>>> S[-1]    # 最后一个元素
'e'
>>> S[-2]    # 倒数第二个元素
'd'
```

严格来说，**负数索引就是直接加上字符串的长度得到正数偏移量**，所以下面两种写法效果相同（尽管第一种更易写、也更不容易出错）：

```python
>>> S[-1]         # 最后一个元素
'e'
>>> S[len(S)-1]   # 负索引的等价写法
'e'
```

注意我们在方括号里可以使用任意表达式，而不只是硬编码的数字字面量 —— 在任何 Python 需要值的地方，我们都可以使用字面量、变量或任意表达式。Python 的语法在这方面是完全通用的。

除了简单的位置索引，**序列还支持一种更通用的索引形式，称为切片**，它可以一步提取整个子部分

```python
>>> S          # 4字符字符串
'Code'
>>> S[1:3]     # 从偏移量1开始切片
'od'
```

理解切片最简单的方式，就是把它看作一步提取字符串中的一整段。

它的通用格式X[I:J]意思是：“给我 X 中从偏移量 I 开始，直到但不包括偏移量 J 的所有内容”，结果会返回一个新对象。
例如前面的第二个操作，就是把字符串 S 中偏移量 1 到 2 的所有字符（即 1 到 3-1）提取成一个新字符串。效果就是切出或解析出中间位于偏移量 1 和 2 的两个字符。

在切片中，左边界默认为 0，右边界默认为被切片序列的长度。这就产生了一些常用写法：

```python
>>> S[1:]      # 从1之后的所有内容
'ode'
>>> S          # S本身没有改变
'Code'
>>> S[0:3]     # 除最后一个字符外的所有内容
'Cod'
>>> S[:3]      # 和 S[0:3] 相同
'Cod'
>>> S[:-1]     # 除最后一个字符外的所有内容
'Cod'
>>> S[:]       # 取出S的全部作为顶层副本
'Code'
```

注意倒数第二个命令中，负偏移量也可以用来作为切片边界；最后一个操作实际上是复制了整个字符串。正如你后面会学到的，复制字符串并没有实际意义，但这种写法对列表等其他序列很有用。

最后，作为序列，字符串还支持用加号+拼接（把两个字符串连成新字符串）和*重复（通过重复另一个字符串创建新字符串）：

```python
>>> S
'Code'
>>> S + 'xyz'   # 拼接
'Codexyz'
>>> S           # S不变
'Code'
>>> S * 8       # 重复
'CodeCodeCodeCodeCodeCodeCodeCode'
```

注意+对不同对象含义不同：对数字是加法，对字符串是拼接。

这是 Python 的一个通用特性，本书中我们经常称之为**多态**—— 简单来说，操作的含义取决于被操作的对象。

##### Immutability - 不可变性

可以在前面的例子中注意到，我们运行的任何操作都没有改变原始字符串。

事实证明，字符串的所有操作都会产生新字符串作为结果，**因为 Python 中的字符串是不可变的 —— 创建后不能原地修改**。

更一般地说，你永远不能覆盖不可变对象的值。例如，你不能通过赋值修改字符串的某个位置，但你总是可以构建一个新字符串并赋值给同一个名称。因为 Python 会自动清理旧对象（后面会学到），所以这听起来效率不高，但实际并非如此：

```python
>>> S
'Code'
>>> S[0] = 'z'   # 不可变对象不允许修改
TypeError: 'str' object does not support item assignment

>>> S = 'Z' + S[1:]  # 但我们可以运行表达式创建新字符串
>>> S
'Zode'
```

Python 中的每个对象都被归类为不可变（不可修改）或可变。就核心对象而言：

- 不可变：数字、字符串、元组

- 可变：列表、字典、集合

这种区别在 Python 编程中至关重要，只是我们目前还无法完全展开。不可变性可以用来保证对象在整个程序中保持不变；相比之下，可变对象的值随时可能被修改（无论你的代码是否预期）

严格来说，如果你确实想原地修改文本数据，可以把它展开成单个字符的列表，再无间隔地重新拼接，或者使用专用的bytearray对象。

```python
>>> S = 'Python'
>>> L = list(S)    # 展开成列表
>>> L
['P', 'y', 't', 'h', 'o', 'n']
>>> L[0] = 'C'     # 修改
>>> ''.join(L)     # 重新合并
'Cython'

>>> B = bytearray(b'app')  # 可变字节数组
>>> B.extend(b'lication')
>>> B
bytearray(b'application')
>>> B.decode()             # 转回字符串
'application' 
```

`bytearray` 支持文本的原地修改，但只适用于所有字符最多 8 位宽的文本（例如 ASCII）。所有其他字符串仍然是不可变的。

`bytearray` 是不可变字节字符串（用 `b'…'` 语法与普通文本字符串区分）和可变列表（用 `[]` 编写和显示）的独特混合体，但我们必须等到后面学习更多相关知识以及 Unicode 文本后，才能完全理解这段代码。

##### Type-Specific Methods - 类型专用方法

到目前为止，我们学习的所有字符串操作实际上都是**序列操作**—— 也就是说，这些操作也适用于 Python 中的其他序列，包括列表和元组。不过，除了通用的序列操作之外，字符串还有自己专属的操作，以方法的形式提供 —— 绑定在特定对象上并作用于该对象的函数，通过带括号的调用表达式触发。

例如，字符串find方法是基本的子串查找操作（返回传入子串的偏移量，不存在则返回 - 1），字符串replace方法执行全局查找与替换；两者都作用于调用它们的对象：

```python
>>> S = 'Code'
>>> S.find('od')    # 查找子串偏移量
1
>>> S
'Code'
>>> S.replace('od', 'abl')  # 替换所有子串
'Cable'
>>> S
'Code'
```

尽管这些字符串方法的名称看起来像是在修改，但我们并没有改变原始字符串，而是创建新字符串作为结果 —— 因为字符串不可变，这是唯一可行的方式。


字符串方法是 Python 文本处理的第一工具。其他方法可以按分隔符拆分字符串（作为简单解析的便捷方式）、进行大小写转换、测试字符串内容（数字、字母等），以及去除字符串两端的空白字符


```python
>>> line = 'aaa,bbb,ccccc,dd'
>>> line.split(',')   # 按分隔符拆分
['aaa', 'bbb', 'ccccc', 'dd']

>>> S = 'code'
>>> S.upper()         # 大小写转换
'CODE'
>>> S.isalpha()       # 内容测试
True

>>> line = 'aaa,bbb,ccccc,dd\n'
>>> line.rstrip()     # 去除末尾空白
'aaa,bbb,ccccc,dd'
>>> line.rstrip().split(',')  # 组合两个操作
['aaa', 'bbb', 'ccccc', 'dd']
```

注意最后一个命令 —— 先去除空白再拆分，因为 Python 从左到右执行，途中会生成临时结果。**你可以像这样链式调用方法，只要前一个调用返回的对象拥有后续方法即可**。

字符串方法也是执行高级替换操作（称为格式化）的一种方式。格式化有三种形式：

- 表达式（老式）
- 字符串方法调用（新式）
- 字面量形式（称为 f-string，最新式）

前两种用独立值替换键，第三种用嵌入的 Python 表达式替换结果，三种运行时都会解析替换值并构建新字符串：

```python
>>> tool = 'Python'
>>> major = 3
>>> minor = 3
>>> 'Using %s version %s.%s' % (tool, major, minor + 9)
'Using Python version 3.12'
>>> 'Using {} version {}.{}'.format(tool, major, minor + 9)
'Using Python version 3.12'
>>> f'Using {tool} version {major}.{minor + 9}'
'Using Python version 3.12'
```

三种都可能遇到。每种形式都有丰富的功能，我们会推迟到本书后面再讨论，当你需要生成可读输出和数字报表时，它们最为重要。

```python
>>> '%.2f | %+05d' % (3.14159, -62)
'3.14 | −0062'
>>> '{1:,.2f} | {0}'.format('sapp'[1:], 296999.256)
'296,999.26 | app'
>>> f'{296999.256:,.2f} | {'sapp'[1:]}'
'296,999.26 | app'
```

虽然序列操作是通用的，但方法不是 —— 虽然有些对象共享部分方法名，但字符串方法通常只适用于字符串，不适用于其他对象。

根据经验，Python 的工具集是分层的：
 - 跨多种对象类型的通用操作体现为内置函数或表达式（例如 `len(X)` 、 `X[0]` ）
 - 而类型专用操作则是方法调用（例如 `aString.upper()` ）
