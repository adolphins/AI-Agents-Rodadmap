### Python

从如今网络上的大多数指标来看，Python 已然是**全球使用最广泛的编程语言**，或者稳居榜首附近。例如，经常被引用的 TIOBE 流行度指数已经连续多年将 Python 列为最受欢迎语言。在本书 2024 年撰写期间，该指数将 Python 排在**第 1 位**，远超紧随其后的 C、C++ 和 Java。

当然，流行度排名容易发生变化，并且依赖于存在争议的使用指标，这些我们在此不做讨论。但基于所有可用信号来看，**Python 革命已然发生**。如今，它在 Web 开发、科学计算、系统管理、人工智能以及几乎所有计算机应用领域中，都是一种**无处不在、首选的语言**。得益于相对简洁的特性，Python 也被广泛用于各类教育场景，帮助初学者入门计算机科学。

事实上，现在可以很肯定地说，**Python 在改变世界的过程中扮演了关键角色**。它引领了一场从静态类型编译语言向动态类型脚本语言的转变，这场变革的深远程度，至少不亚于早年从机器语言向编译语言的过渡。脚本语言的转型不仅让许多过去不切实际的任务成为可能，还向非专业开发者敞开了大门。在此过程中，它将计算机推向了数十年前无法想象的重要地位。例如，如果没有 Python 这类工具，互联网根本不可能成为今天的样子。无论好坏，Python 都在驱动着新事物的诞生。

抛开宏大目标不谈，这一切对本书有两个实际意义：
第一，因为现在已经是 Python 革命后的时代，这一版本比前几版少了很多“宣传式”的内容。没必要浪费时间推广一个已经普及的工具。本书仍会在第 1 章总结 Python 的价值，但你在学习基础知识后可能探索的领域和工具，在网上随处可得，且更新过于频繁，无法在一本基础书中全面覆盖。

第二，Python 的流行意味着，通过阅读本书，你将掌握一项**极具价值的技能**，它能帮助你完成各类计算机软件任务。学习 Python 会让你轻松进入多个技术领域，并实现那些原本困难甚至不可能完成的编程目标。如今的 Python 用户可以享用大量现成的技术成果，用这门语言大幅提升工作效率。

话虽如此，Python 并非唯一选择。从头系统学习计算机科学——也就是开发者所说的“全栈”知识——对你同样有益。例如，学习 C、Java 这类底层语言，仍然能比只学脚本语言提供更完整的视角，并帮助你解决复杂问题。毕竟，**最常用版本的 Python 本身就是用 C 语言写的**。

即便如此，Python 仍是极佳的起点，也足以胜任大量任务。虽然它并非完美无缺，也面临着当今软件行业常见的频繁变动问题，但无数开发者仍然觉得 Python 比其他工具更有乐趣。例如，Java 和 C++ 看起来像是为中层管理设计的语言：它们用各种“保护枷锁”和繁琐规则束缚开发者，却与程序目标关系不大。与之形成鲜明对比的是，Python 始终更像**助手，而非障碍**。这种观点自然带有主观性，但你来到本书，正好可以亲自体验并做出判断。


### This Book 关于这本书

本书是一部 Python 语言教程，也是该领域的经典之作。它凝聚了作者**三十年**使用、推广与教授 Python 的经验，其渊源可追溯至 20 世纪 90 年代中期——那时 Python 还停留在 1.X 版本，互联网也只是开发者们午餐时闲聊的话题。尽管本书的重心牢牢立足于当下，但这份传承自然带来了一些历史背景，帮你更深刻地理解 Python。不管你听过什么说法，历史都至关重要，尤其在知识领域。

同样重要的是，本书始终基于**初次学习 Python 的初学者**真实、一线的反馈。这些反馈主要来自作者长达二十年的 Python 培训课程。虽然这类课程如今已像渡渡鸟和雅虎一样成为历史，但本书特意保留了这些源自学习者的内容，因为这正是本书的核心价值所在。

因此，如果你和成千上万被本书收录经验的学习者一样，你会发现本书就像一套**自主进度版的 Python 培训课程**，正是从这些课程中演变而来。你甚至有时会发现，它在你提出问题之前就给出了答案——因为无数前人已经问过同样的问题。这并非未卜先知，只是说明：**最优秀的学习资源，一定是倾听学习者的。**

另外值得提前说明的是，本书在介绍 Python 变更的同时，有时也会对其提出批判。批判性思维在工程领域至关重要，尤其是在一个陷入“军备竞赛”、让数百万人使用的工具变得复杂的领域。在某些层面上，Python 依旧是一个不断变化的创意试验场，往往把“变更者的傲慢”置于用户需求之上，而本书并不避讳指出这一点。话虽如此，本书的核心目标是**教学，而非批判**，观点终归只是观点。尽管书中看法反映了数十年使用与教授 Python 的经验，但你始终应自行判断 Python 各项变更的真正价值。


### This Edition 关于第六版

这一版本完全删除了对 Python 早期版本 2.X 的讲解，新增了对 Python 3.X（更新且不兼容的版本）近期更新内容的介绍。2013 年本书上一版出版时，Python 2.X 仍被广泛使用，甚至占据主导地位。正因如此，上一版不得不同时讲解成熟的 2.X 和新兴的 3.X，有时难免让内容变得繁杂混乱。

十多年后的今天，2.X 已正式停止维护，Python 社区已全面转向 3.X，对如今的学习者而言，2.X 只会造成不必要的干扰。因此，在沿用数十年后，本书彻底移除了 2.X 专属内容，为 3.X 新特性腾出空间，同时也控制了全书篇幅。严格来说，这一版本已更新至适配 **Python 3.12** 及同期版本，也前瞻了 3.13 的改动；而本书对基础核心的聚焦，让内容同时适用于新旧 Python 版本。

在邮件纷至沓来之前，本书先明确说明：我们对失去部分历史背景感到遗憾（内心也怀念 2.X 更简洁的时代）。但 3.X 本身已是体量庞大的主题，没必要为一个现已极少使用的版本拆分内容、增加篇幅。所以，安心走入良夜吧，Python 2.X；Python 3.X 万岁。除非特别说明，这一版本中提到的“Python”均泛指 **3.X 系列**，特指 **3.12 及更高版本**。

在 3.X 特性方面，这一版本新增讲解内容包括：f-string 字符串字面量、海象运算符（:=）命名赋值表达式、match 语句、类型注解、异步协程、星号解包扩展、数字下划线分隔符、`__main__.py` 包文件、`__getattr__` 模块钩子、`except*` 异常组、字典键插入顺序、纯位置函数参数、基于哈希的字节码文件，以及过去十多年间出现的其他新增、弃用和变更特性。

其中，**类型注解与异步协程未做深入讲解**——这是刻意设计的。前者是可选的理论工具，Python 本身完全不依赖它，且与核心设计理念相悖；后者是高级应用工具，自诞生以来便持续变动。两者都会快速攀升至过高的复杂度，超出初学者的学习范围。如确有需要，这些细分主题的补充资料在网上随手可查。本书的目标是：**先稳稳学会走，再尝试跑**。

## Part I. Getting Started（起步）


### Chapter 1. A Python Q&A Session 问答环节

如果你正在阅读本书，或许你已经了解 Python 是什么，以及为什么它是一门值得学习的重要工具。如果你还不了解，可能要等到读完本书剩余内容、亲手完成一两个项目后，才能真正认同 Python 的价值。但在深入细节之前，本章将先简要介绍 Python 广受欢迎的核心原因，并逐步给出这门语言的定义。本章将以问答形式展开，解答像你一样的初学者最常提出的一些问题。

#### Why Do People Use Python? 为什么什么使用 Python？

由于市面上有众多编程语言可供选择，这通常是初学者最先提出的问题，也是一个绝佳的起点。鉴于如今已有数百万人使用 Python，我们很难完全精确地回答这个问题；开发工具的选择往往取决于特定的约束条件或个人偏好。

但在为数百个团队、数千名学生教授 Python 之后，我总结出了一些共通的原因。Python 用户选择它的主要因素包括：

**软件质量**
对许多人而言，Python 对可读性、一致性和软件整体质量的重视，使其在编程工具中脱颖而出。Python 代码专为可读性而设计，因此具备高度的可复用性与可维护性——远超传统脚本语言。Python 代码风格统一，即使不是你编写的，也相对容易理解。此外，Python 对面向对象（OO）、函数式编程等更高级的软件复用机制提供了强大支持，可进一步提升代码质量。

**开发效率**
Python 能将开发者的效率提升数倍，远超编译型语言或静态类型语言。一个直观的衡量标准是：实现相同功能，Python 代码量通常仅为 C++ 或 Java 的 1/3 到 1/5。这意味着更少的代码输入、更少的调试工作，以及更少的后期维护成本。大多数 Python 程序还能直接运行，无需其他工具所必需的漫长编译与链接步骤，进一步提升了编程速度。

**程序可移植性**
Python 程序通常可以在所有主流计算机平台上**不经修改直接运行**。例如，将 Python 程序从 Linux 迁移到 Windows，往往只需要把代码复制过去即可。此外，Python 提供多种方式编写可移植的图形界面、数据库访问程序、Web 系统等。即使是程序启动、目录处理等高度系统相关的接口，在 Python 中也能做到最大程度的可移植。

**丰富的应用支持**
Python 附带了大量预先构建、可移植的功能集合，即**标准库**。这个库支持从文本模式匹配到网络脚本等各类应用级编程任务。此外，Python 还可以通过自研库与海量第三方软件进行扩展。如后文所述，Python 的第三方生态提供了网站开发、数值计算、人工智能等各种工具。例如，NumPy 扩展已让 Python 成为 STEM（科学、技术、工程、数学）领域的核心工具；Django 和 PyTorch 则分别在 Web 开发与人工智能领域起到了同样的作用。

**组件集成能力**
Python 脚本可以通过多种集成机制与应用的其他部分通信。这种集成能力让 Python 可用作产品定制与扩展工具。例如，Python 代码可以调用编译型库、被编译程序调用、通过网络与其他组件交互，并在智能手机上使用 Android 和 iOS 工具包。事实上，包括文件操作在内的许多 Python 核心工具，最终都会使用预先编写的系统库接口；即使你的程序完全由 Python 编写，它也并非孤立运行。

**对编程的热爱**
Python 简单易用、内置工具丰富，能让编程从苦差事变成乐趣。尽管这种优势无形且主观，但它对生产力的提升至关重要。人们确实靠编写 Python 获得报酬，但许多人使用它仅仅是因为乐趣——这在软件领域相当罕见。

在这些因素中，**前两项——质量与效率**，对大多数 Python 用户来说可能是最具说服力的优势。下面我们来进一步详细了解。


##### Software Quality 软件质量

Python 在设计上拥有**简洁易懂的语法**和**高度一致的编程模型**。正如早期一次 Python 技术会议上的口号所言，最终效果是：Python 仿佛天生契合你的大脑。也就是说，语言的各种特性以一致、有限的方式相互配合，并自然地遵循一小组核心概念。这让这门语言更容易学习、理解和记忆。在实际开发中，Python 程序员在阅读或编写代码时，不必频繁查阅手册，代码本身通常就清晰易懂。

从设计理念上，Python 秉持**极简主义思想**。这意味着，尽管完成一个编程任务往往有多种方法，但通常**只有一种最清晰、最标准的方式**，少数几种不那么直观的备选方案，以及一整套连贯统一的交互规则。此外，Python 通常不会替你做出随意的决策；当交互行为存在歧义时，它更倾向于**显式表达**，而非“魔法般的隐式操作”。在 Python 的设计哲学中，**显式优于隐式，简洁优于复杂**。

除了这些设计理念，Python 还提供了模块、面向对象编程（OOP）等工具。在你即将掌握的熟练运用下，这些工具能自然而然地提升代码可复用性。而且，因为 Python 本身注重质量，大多数 Python 程序员也会自然养成高质量编码的习惯。当你需要使用他人编写的 Python 代码时，这会成为一项至关重要的优势。

##### Developer Productivity 开发效率

如果你曾在软件行业工作，就会知道这行充满变化与挑战。在 20 世纪 90 年代中后期的互联网繁荣时期，企业很难招到足够的程序员来完成软件项目；开发者被要求以互联网迭代的速度快速实现系统。而在随后的经济衰退与裁员潮中，情况发生了转变：编程团队经常需要用**更少的人力完成同样多的任务**。

在这两种场景下，Python 都表现出色，让程序员能用更少的精力完成更多工作。它专为**快速开发**而优化：简洁的语法、动态类型、无需编译步骤，以及丰富的内置工具集，让开发者使用 Python 编写程序的时间，远短于使用其他许多语言。

最终效果是：Python 通常能将开发者的效率提升数倍，远超传统语言，并且常常让“不可能完成的任务”成为可能。无论行业处于繁荣期、衰退期，还是两者之间的任何阶段，这都是一个好消息。


#### Is Python a “Scripting Language”? Python 是一门“脚本语言”吗？
或许是。Python 经常被用于脚本场景，但并非总是如此。它常被称作**面向对象的脚本语言**——这个定义将面向对象支持与脚本场景定位结合在了一起，但可能过于狭隘、片面。

如果必须用一句话概括，Python 更准确的定位是：

*A general-purpose programming language that blends procedural, functional, and object-oriented paradigms and accelerates software development by reducing complexity.*

*一门融合了过程式、函数式和面向对象范式的通用编程语言，它通过降低复杂度来加速软件开发。*

这句话印在 T 恤上可能不太好看，但它准确捕捉了今日 Python 的丰富性与适用范围。

尽管如此，“脚本”这个词还是像胶水一样牢牢贴在了 Python 身上，这或许是为了与其他需要更大工作量的工具形成对比。例如，有些人用“脚本”而不是“程序”来描述 Python 代码文件，因为编码看起来更简单、不那么正式。更实用的是，另一些人把“脚本”特指顶层文件，把“程序”用于更复杂的多文件应用——这两种用法在 Python 中都很常见。

然而，“脚本语言”这个词对不同人有截然不同的含义，因此有些人希望完全不要把它用在 Python 身上。事实上，当人们听到 Python 被贴上这个标签时，通常会产生三种非常不同的理解，其中一些更有参考意义：

##### 1. Shell 工具

有时人们听到 Python 被称为脚本语言，会认为它只是用于编写**操作系统脚本**的工具。这类程序通常从控制台命令行启动，用于处理文本文件、启动其他程序等任务。

正如你稍后会学到的，Python 确实可以承担这类角色，但这只是 Python 几十个常见应用领域中的一个。它**不只是一门更好的 Shell 脚本语言**。

##### 2. 控制语言
对另一些人来说，“脚本”指的是用来**控制和协调其他应用组件**的“胶水”层。如前所述，Python 确实经常用在大型应用的场景中。例如，测试硬件设备时，Python 程序可以调用提供底层设备或端口访问的组件。

同样，程序可以在关键位置运行小段 Python 代码，支持终端用户定制产品，而无需交付和重新编译整个系统的源代码。

Python 的简洁性让它天然成为灵活的控制工具。但严格来说，这也只是 Python 的常见用途之一；许多（也许是大多数）Python 程序员编写独立脚本，从未使用或了解任何集成组件。它**不只是一门控制语言**。

##### 3. 易用性
“脚本语言”这个词最恰当的用法，是指**相对简单、能快速完成编码任务**的语言。用在 Python 身上尤其贴切——它比 C++ 这类编译型语言或 Java 这类大型语言开发速度快得多。它快速的开发周期催生了一种探索式、增量式的编程模式，这种模式只有亲身体验才能领会。

但不要被误导——Python **并不只用于简单任务**。相反，它凭借易用性和灵活性让任务变简单。Python 拥有友好的功能集，但也允许程序按需扩展复杂度。因此，它既常用于快速的战术任务，也适用于长期的战略开发。

所以，Python 到底是不是脚本语言？答案取决于你问谁（以及什么时候问）。一般来说，“脚本”这个词最好用来描述 Python 所支持的**快速、灵活的开发模式**，而不是把它当成某个特定应用领域或限制性标签。

顺便一提，人们有时也把 Python 称作**解释型语言**，以区别于 C、C++ 等语言。虽然这有时也是一种刻板印象，但更容易澄清：如今 Python 有多种实现，从传统解释器到传统编译器应有尽有，因此“解释型”并不准确。

更清晰的区别是：**Python 是动态类型语言**，而非像常见编译型语言那样的静态类型语言。你很快就会学到，这正是 Python 在开发任务中强大能力的主要来源。

#### OK, but What’s the Downside? 好吧，但 Python 有什么缺点？
在 Python 三十多年的发展历程中，**公认的唯一短板**，或许也是它追求易用性所带来的必然取舍：**Python 的运行速度，往往比不上 C、C++ 这类完全编译的底层语言**。

如今这种场景虽已不多见，但在部分任务中，你偶尔还是需要借助更贴近硬件底层的语言，来实现极致性能。

我们会在第 2 章讲解 Python 的运行原理，简单来说：目前最主流的 Python 版本，会先把源代码语句**编译**成一种叫作**字节码**的中间格式，再对字节码进行解释执行。
字节码具备跨平台可移植的特性，但因为 Python 通常不会直接编译成二进制机器码（比如电脑、手机里英特尔或ARM芯片可直接执行的指令），所以部分程序的运行速度，会慢于 C 这类完全编译型语言。

你是否会在意这种运行速度差异，取决于你开发的程序类型。
Python 一直在持续优化，在绝大多数应用场景下，它本身的运行速度都完全够用。
而且，当你在 Python 脚本中做实际业务操作时——比如处理文件、搭建图形界面（GUI），程序其实是以 **C 语言的速度** 运行的，因为这类底层操作都会交由 Python 解释器内部的 C 编译代码去执行。

事实上，如今纠结 Python 运行速度有点**本末倒置**：
很多对运行性能要求极高的领域，依然在广泛使用 Python。例如数值计算、游戏开发，这类场景往往要求核心运算模块达到 C 语言甚至更高的速度，但整体项目依旧常用 Python 来开发。

如果确实需要极致性能，Python 也有多种提速方案：
比如 **PyPy** 可以在程序运行时对字节码做进一步编译优化；**Cython** 支持编写 Python 与 C 的混合代码并完整编译；还可以把核心高频代码剥离出来，写成编译扩展库，再链接到 Python 脚本中调用。

典型例子是数值计算库 **NumPy**：它将经过编译和深度优化的底层库与 Python 语法结合，让 Python 变成了**既高效又易用**的数值编程工具。实际使用中，NumPy 的运行速度完全可以媲美 Fortran、C++，却省去了后者复杂的开发成本。

更本质地说，**运行速度并不是大多数软件开发的唯一追求**。
Python 带来的**开发效率提升**，往往远比运行速度的小幅损耗更有价值，尤其在如今硬件性能充足、项目交付工期紧张的环境下更是如此。

当然 Python 也存在其他潜在不足，比如版本迭代频繁、部分设计愈发繁杂等，但这些都因人而异，最好跟着本书学习之后，再由你自己做出评判。

#### Who Uses Python Today? 如今谁在使用 Python？

由于 Python 是**免费开源软件（FOSS）**，无法精确统计其用户规模——它不存在需要登记的软件授权许可。

此外，无数 Linux 发行版、苹果 Mac 电脑，以及各式各样的产品和硬件设备都**默认预装**了 Python，这进一步加大了用户总量的统计难度。

尽管无法精确统计，但总体而言，Python 拥有**极其庞大的用户群体**和活跃的开发者社区。目前它稳居全球**使用最广泛的五大编程语言之列**，在很多榜单中更是常年排名第一。

Python 历经三十多年广泛应用，整体生态已经非常成熟、稳定且可靠。

正因如此，众多正规企业都将 Python 用于**能够产生实际营收的商业产品**中。虽然合作厂商名单会不断变化，但目前知名的 Python 使用者几乎囊括了软件行业的顶尖企业：

从更广的范围来看，如今绝大多数软件开发机构，都会把 Python 用于**战略核心开发或临时项目开发**；同时它也是计算机科学教育领域的**首选教学语言**。
Python 不局限于单一用途，几乎可以胜任所有开发场景。

#### What Can I Do with Python? Python 能用来做什么？

商业应用固然很有说服力，但人们也会把 Python 用于各种各样现实生活中的日常任务，无论是为了盈利、工作需求、个人爱好还是纯粹娱乐。事实上，作为一门**通用编程语言**，Python 的应用场景几乎没有限制：从游戏开发、网站开发，到机器人技术、内容管理系统，你都可以用它来实现。

即便如此，Python 的用途大致可以归为几大类别。接下来几小节，我们将介绍目前 Python 最常见的应用领域，以及每个领域中主流的开发工具。

先提前说明两点：

第一，无论是本章还是全书，都无法深入讲解这些工具。例如 NumPy、Django 本身各自都能单独写成一本书。本书的目标是帮你学好 **Python 基础语法**，为后续使用这些框架和库打好底子。

第二，受限于篇幅，还有很多优秀工具无法一一列举；如果你对下面某个领域感兴趣，可以自行上网查找更多相关工具和学习资源。

##### Systems Programming 系统编程

Python 内置了访问操作系统服务的接口，非常适合编写**可移植、易维护**的系统管理工具——有时也被称作 Shell 工具或命令行工具，用途十分广泛。
Python 程序可以搜索文件和目录树、启动和配置其他程序、通过进程/线程/协程实现并行处理等等。

Python 标准库提供了 *可移植操作系统接口（POSIX）* 绑定，支持所有常见的系统功能：环境变量、文件操作、网络套接字、管道、进程、线程、正则表达式匹配、命令行参数、标准流接口、调用系统命令、文件名通配、ZIP 压缩工具，以及 XML、JSON、CSV 解析器。
此外，Python 的系统接口大多具备跨平台特性：例如一个复制目录树的脚本，几乎不用修改就能在所有安装了 Python 的平台上直接运行。

##### GUIs and UIs 图形界面与用户界面开发
Python 语法简洁、开发迭代快，也非常适合在各类设备上开发 **图形界面（GUI）** 应用。
例如 Python 自带面向对象的 GUI 工具包接口 **Tkinter**，可以开发拥有原生外观、跨平台的图形界面程序。基于 Tkinter 开发的程序无需修改，就能在 Windows、macOS、Linux 上运行，借助免费应用还可在安卓设备上使用（详见附录 A）。

同时还有大量第三方工具支持跨平台 UI 开发：
- 传统图形界面框架包括 Kivy、BeeWare 的 Toga、PyQt、wxPython；
- 基于浏览器的方案有 Django、Flask、WebAssembly 等。
- 绝大多数应用都需要和用户交互，而 Python 提供了多种**一次编写、随处运行**的界面开发方案。

##### Internet and Web Scripting 互联网与网络脚本开发
Python 自带网络相关标准库，支持以客户端和服务端两种模式实现各类网络编程任务。
脚本可以通过套接字通信、解析网页表单数据、通过 FTP 传输文件、解析生成 XML/JSON 文档、收发解析邮件、根据网址抓取网页并解析 HTML 等。

网络上还有海量第三方库与框架支持 Python 网络开发：
Django、Flask、TurboGears、Zope 等 Web 框架，可用来开发功能完备、可投入生产环境的网站。这类框架大多内置**对象关系映射、服务端脚本、模板引擎、AJAX 支持**，提供企业级完整 Web 开发解决方案。
Pyjamas 可将 Python 转译为 JavaScript；Beautiful Soup 用于网页 HTML 解析提取；WebAssembly、Pyodide、py2wasm、PyScript 等还能让 Python 直接在浏览器中运行，进一步拓展了 Web 开发的可能性。

##### Component Integration 组件集成开发
前文已经提到过组件集成的作用。Python 可以被 C、C++、Java 编写的系统**扩展和嵌入**，非常适合充当灵活的**胶水语言**，用来调度和控制其他软件组件的行为。

例如把 C 语言库集成到 Python 中，就可以用 Python 调用、测试库中的功能；把 Python 嵌入软件产品内部，还能支持现场自定义功能，无需重新编译整个项目，也不用对外交付源代码。

SWIG、Boost.Python、CFFI、HPy 等工具可以自动完成编译组件与 Python 脚本的对接工作；Cython 支持混合编写 Python 和类 C 代码，生成可编译扩展模块。
其他组件互联方案还有：pyjnius、Chaquopy 实现 Python 与 Java 互通；pywin32 支持 Windows 组件对象模型（COM）；REST、SOAP、XML-RPC 实现跨网络调用；Jython 可运行在 Java 平台、IronPython 可运行在 .NET 平台。
简单来说，绝大多数软件组件，都能和 Python 代码联动协作。

##### Database Access 数据库访问
针对传统数据库场景，Python 提供了市面上所有主流关系型数据库的接口：Oracle、MySQL、PostgreSQL、Informix、ODBC、SQLite 等。
Python 还定义了一套**可移植数据库 API**，无论底层使用哪种数据库，Python 脚本的调用方式都保持一致。
对于基础数据存储需求，Python 原生支持对象序列化 pickle、跨语言 JSON 格式，以及进程内嵌入式 SQLite 数据库。

在 Python 生态中：PyYAML 用于解析生成 YAML 数据；ZODB、Durus 提供面向对象数据库；SQLObject、SQLAlchemy 实现**对象关系映射（ORM）**，可以把 Python 类直接映射到数据库表；PyMongo 可对接高性能文档数据库 MongoDB。
同时 Python 也能便捷接入谷歌 App Engine、微软 Azure、亚马逊 AWS 等云存储服务。

##### Rapid Prototyping 快速原型开发
在 Python 程序看来，用 Python 写的组件和用 C 写的组件几乎没有区别。
正因如此，可以先用 Python 快速搭建系统原型，后续再把性能要求高的核心组件改用 C、C++ 等编译型语言重构交付。
原型定型后，不需要追求编译高性能的模块可以继续保留 Python 版本，方便后期维护和迭代。
值得注意的是：凭借前文提到的各种优化方案，很多时候**原型本身就足以直接作为最终产品上线使用**。

##### Numeric and Scientific Programming 数值计算与科学编程
Python 在**数值与科学计算**领域应用极广。这一领域传统上并不属于脚本语言的擅长范围，如今却成了 Python 最核心的优势场景之一。
前面提到的高性能数值计算库 **NumPy**，内置数组对象、标准数学库接口等高级工具；它将 Python 与编译型语言编写的数值运算底层结合，兼顾简洁易用与运行效率，足以替代 Fortran、C++ 编写传统数值程序。

大量科学计算工具都以 NumPy 为底层核心，扩展出可视化、并行计算、统计分析等能力：
SciPy 提供完整科学计算工具库；pandas 专注数据分析；matplotlib 实现数据可视化；Jupyter 笔记本专为科研数学工作者设计；Numba、PyThran 分别为 Python 数值代码提供即时编译（JIT）和提前编译（AOT）优化；前文提到的 Cython、PyPy 也能对算法代码做性能优化。
对于基础数学需求，Python 标准库自带统计模块、复数运算、定点数、有理数运算等工具，本书后续也会逐一讲解。

##### And More: AI, Games, Images, QA, Excel, Apps… 更多领域：人工智能、游戏、图像处理、自动化测试、Excel、手机应用……
Python 的应用领域和相关工具远不止以上这些，还包括：
- 人工智能（PyTorch、TensorFlow、Keras）
- 游戏开发（pygame、Panda3D、Kivy）
- 图像与图形处理（Pillow、PyOpenGL、OpenCV）
- 软件质量保障与自动化测试（PyTest、unittest、Selenium）
- Excel 表格自动化（xlwings、PyXLL 等）
- 智能手机应用开发（Kivy、BeeWare，详见附录 A）
- 单片机与串口开发（MicroPython、PySerial）
- 以及更多其他领域。

想要查找这些领域的学习资源，可以查阅维基百科 [List of Python software](https://en.wikipedia.org/wiki/List_of_Python_software)、 [PyPI官网](https://pypi.org/)（pip 安装库的平台），或是直接网页搜索。

虽然各类应用场景体现了 Python 极强的实用价值，但本质上大多都是 Python **组件集成能力**的延伸：用 Python 作为 C 等编译库的前端调度语言，就能适配各行各业的脚本开发需求。
作为一门支持集成扩展的通用编程语言，Python 的适用范围几乎覆盖全行业。

#### What Are Python’s Technical Strengths? Python 的技术优势有哪些？

当然，这是开发者视角的问题。如果你没有编程基础，接下来几小节里的专业术语可能会让你有点困惑——不用担心，随着本书后续内容的学习，这些知识点都会详细讲解。

但无论你现在是不是开发者，下面先快速梳理 Python 最核心的技术特性。其中部分内容前文已经提过，本节会做更完整的补充说明。

##### It’s Object-Oriented and Functional 它兼具面向对象与函数式特性
Python 从底层设计起就是一门**面向对象语言**。在本书后续你会学到，它的类模型支持多态、运算符重载、多重继承等高级特性；而且依托 Python 简洁的语法和类型机制，面向对象编程用起来格外简单。事实上，就算你完全不懂这些专业名词，也会发现：用 Python 学面向对象，几乎比其他所有同类语言都更容易上手。

同样重要的是：**面向对象在 Python 中只是可选方案**。你完全不用一开始就精通面向对象也能写出大量实用程序。和 C++ 类似，Python 同时支持**过程式编程**与**面向对象编程**两种模式。你可以根据实际场景和开发需求，灵活选择是否使用面向对象特性。这一点在临时快速开发中尤其实用——这类场景往往没有时间做完整架构设计，也就很难发挥面向对象的设计优势。

除了原生的**过程式（基于语句）**和**面向对象（基于类）**范式，如今 Python 还内置支持**函数式编程**，主要包括：生成器、推导式、闭包、map 映射、装饰器、匿名 lambda 函数、一等公民函数对象等。本书后面也会讲到，这些特性既可以和面向对象工具互补，也可以作为替代方案单独使用。

##### It’s Free and Open 免费且开源
Python 完全**免费使用、免费分发**。和 Linux、Apache 等开源软件一样，你可以在网上免费获取 Python 整套系统的源代码。你可以随意复制、嵌入自己的软件、随产品一同发布，没有任何使用限制。

但不要误解：“免费”不等于“无人维护、没有支持”。恰恰相反，Python 拥有海量线上资源社区，遇到问题求助、排障的响应速度，远超大多数商业软件。
更重要的是，Python 开放完整源码，这是闭源商业软件做不到的优势。
并不是每个人都有兴趣去研读或修改编程语言底层实现代码，但知道**你拥有这个权限**本身就很安心。你不必受制于商业厂商的规则和决策，因为最权威的终极文档——**源代码**，随时可以作为你最后的参考依据。

##### It’s Portable 它具备可移植性
前文已经简单提过可移植性。Python 标准实现采用可移植的 ANSI C 编写，几乎能在当下所有主流平台编译并运行。
如今从智能手机到超级计算机，都可以运行 Python 程序。部分平台举例：Windows、macOS 电脑；Linux、Unix 工作站与服务器；安卓、iOS 手机平板；VxWorks 实时系统、克雷超级计算机、IBM 大型机等等。而且适配平台还在持续增加；本书撰写之时，安卓和 iOS 也正在获得 Python 官网的官方正式支持。

和语言本身一样，Python 自带的**标准库模块**也做了跨平台兼容设计。比如文件操作工具，屏蔽了不同操作系统专属的存储差异。
此外，Python 程序会自动编译为**跨平台字节码**，只要设备安装了对应版本的 Python，字节码就能无差别运行（下一章会详细讲解）。同时前文提到的传统图形界面、网页方案，也都能帮你写出跨平台的用户界面程序。

这意味着：只要使用 Python 语法、标准库和跨平台扩展库编写的程序，在绝大多数装有 Python 解释器的系统上都可以**直接运行、无需修改**。Python 也支持各平台专属扩展（如 Windows 的 pywin32、macOS 的 PyObjC、安卓的 pyjnius），但 Python 语言本身在所有平台的使用体验完全一致。

##### It’s Powerful 它功能强大
从特性上来看，Python 属于**混合型语言**。
它的功能定位介于传统脚本语言（如 Tcl、Scheme、Perl）和系统开发语言（如 C、C++、Java）之间。它既有脚本语言的简洁易用，又具备编译型语言才有的高级软件工程能力。和部分脚本语言不同，这种组合让 Python 也能胜任**大型项目开发**。
先提前预览 Python 自带的核心能力：

###### 动态类型
程序运行时，Python 自动识别对象类型，不需要你在代码中编写复杂的类型、内存大小声明。事实上你在第 6 章会学到：Python 中**完全没有类型和变量声明**这一概念（新版的类型提示只是标注，Python 本身并不会强制执行）。因为不限制数据类型，同一段 Python 代码通常可以自动适配多种对象。

###### 自动内存管理
Python 自动为对象分配内存，当对象不再被使用时，会自动回收内存（垃圾回收）。Python 会全程跟踪正在使用的对象及其占用内存，无需开发者手动管理。

###### 大型项目开发支持
为构建大型系统，Python 提供**模块、类、异常处理**等工具。可以把系统拆分为独立组件，用面向对象实现代码复用与定制，优雅处理程序异常和错误。前文提到的函数式编程特性，也能实现同样的架构设计目标。

###### 内置数据类型
Python 原生内置列表、字典、字符串等常用数据结构。这些内置类型灵活易用、可按需伸缩大小、可任意嵌套表达复杂数据结构，还能规避常见的内存操作错误。

###### 内置操作工具
针对各类内置数据类型，Python 提供强大的标准操作：拼接、切片、排序、映射等等。

###### 标准库工具
面对各类具体业务场景，Python 自带海量现成库工具，从正则匹配到网络服务器开发应有尽有。学会 Python 基础语法后，大部分应用开发其实都是在使用标准库。

###### 第三方扩展库
开源属性鼓励开发者贡献各类第三方工具，弥补内置库的功能空白。网上有大量免费库可用于图像处理、数值计算、数据库开发、网站搭建、自动化测试等（详见前文《Python 能用来做什么？》）。

即便拥有如此丰富的工具集，Python 依旧保持**极简的语法和设计**。最终形成一门：兼具脚本语言易用性、功能又极其强大的编程工具。

##### It’s Mixable 可混合编程
前文提到，Python 程序可以通过多种方式，**轻松对接其他语言编写的组件**，既可本地调用，也可跨网络通信。你可以按需为 Python 扩展功能，也能把 Python 程序嵌入其他系统环境中使用。

把 Python 嵌入底层高性能语言开发的系统中，它就能作为简易前端，用于功能测试和自定义配置。同时这也让 Python 非常适合**快速原型开发**：先用 Python 快速搭建整套系统原型，后续如有性能需求，再逐块改用编译型语言开发扩展模块提升运行速度。

##### It’s Relatively Easy to Use 上手相对简单
和 C++、Java、C# 等语言相比，大多数人都会觉得 Python 编程**极其简洁轻松**。大多数场景下，写完代码直接就能运行，没有 C/C++ 那种繁琐的编译、链接中间步骤。Python 即时执行程序，编程交互体验极好；修改代码后能立刻看到运行效果，很多时候刚敲完代码就能看到结果变化。

当然，开发流程简洁只是 Python 易用性的一方面。它还有刻意设计的极简语法、强大的内置工具。甚至有人评价：Python 就是**可直接运行的伪代码**。相比同期其他语言，Python 剔除了大量冗余复杂度，实现同样功能，代码更简短、更灵活。

但这不代表编程可以不动脑子。Python 也有自身复杂的设计和晦涩的细节，本书后续都会直面讲解；部分场景的开发效率也并非都一样。比如 Python 的面向对象继承机制，如今比早期版本复杂不少；开发独立桌面应用、预编译程序的速度依旧偏慢。但横向对比同类语言，Python 对开发者依然友好得多。

##### It’s Relatively Easy to Learn 学习门槛相对更低
最后，也正是本书的初衷：和其他主流编程语言相比，**Python 核心语法非常容易入门**。如果你已经有编程经验，几天内就能写出小型 Python 程序——但别被宣传误导，不要以为很快就能成为行业专家。

当然，想要精通如今功能完备的 Python 绝非易事，本书剩余内容也将专注带你系统掌握。但投入时间学好 Python 绝对值得：学成后你掌握的编程能力，几乎可以适配所有计算机应用领域。而且大多数人都会觉得，Python 的学习曲线远比其他开发语言平缓，虽然不像部分营销宣传说的那样“零难度”，但入门友好度确实很高。

这对两类人都是好消息：想扩充技术栈的专业开发者，以及使用带 Python 脚本扩展功能软件的普通用户。如今很多软件系统，都依靠 Python 易学的特性，让用户不用专业培训也能上手自定义使用。同时催生了一大批出于工作需求或兴趣爱好编程的用户，他们不一定需要专业大型软件开发能力。

虽然 Python 有本书后续要讲的高级特性，但它的**核心基础知识**，无论零基础新手还是资深开发者，都能轻松掌握。

想要亲自感受这些优势，那我们就结束概述，正式开始动手写代码吧。

做得怎么样？以下是参考答案（部分题目可能有多个正确答案）。再次建议：即便你自认答对了，也不妨看看参考答案，补充更多背景理解。如果对答案有不理解的地方，可以回看本章对应内容。

但另一方面，绝大多数应用场景下 Python 速度完全够用；而且常规 Python 代码实际运行时会调用解释器内部链接的 C 语言代码，运行速度接近 C 语言水平。
如果对运行速度要求极高，可以使用编译扩展、Cython 等工具，对程序中数值计算密集的部分做性能优化。

4. 只要是计算机能做的事，几乎都可以用 Python 实现：从网站开发、游戏制作，到人工智能、航天器控制等。
目前数值计算和 Web 开发是 Python 的主流应用领域，这也恰好契合了计算机最核心的两大用途。
