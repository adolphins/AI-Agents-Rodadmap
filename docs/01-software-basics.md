# 第 1 层：软件基础【必须】

> 学习目标：建立 Python 编程、Git、Web 开发的扎实基础

---

## 学习要点

### Python 高级特性（OOP / Concurrent）

- [ ] 面向对象编程（OOP）的四大特性
- [ ] 装饰器（Decorators）与元编程
- [ ] 异步编程（Async/Await）与并发
- [ ] 类型提示（Type Hints）与类型检查

### Git 版本控制

- [ ] Git 基本命令与工作流
- [ ] 分支管理与合并冲突解决
- [ ] GitHub / GitLab 协作工作流

### Web 开发基础

- [ ] HTTP 协议与 RESTful API
- [ ] JSON 数据格式
- [ ] FastAPI 框架基础
- [ ] 请求/响应处理

## 学习建议

1. **不要跳过基础**：虽然看起来简单，但扎实的基础对后续学习很重要
2. **动手实践**：每个知识点都要写代码练习
3. **构建项目**：用 FastAPI 构建一个简单的 Web 服务，包含数据库操作
